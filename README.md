# 第十一号失主（新版）

捡到一个没写名字的铁盒，靠盒子里的东西一间一间找它的主人。
已做完整条线：**开场（群聊、寄存处、铁盒）→ 灯光间 → 道具间 → 后台 → 后厨与结尾**。

纯静态前端，不需要构建。旧版《失名之夜》在另一个仓库 `lost-name-night`。

## 运行

在本目录：

```sh
python -m http.server 8765
```

打开 `http://127.0.0.1:8765/`。声音在 `assets/audio`（CC0，来源见该目录的 CREDITS.md，只带了用到的五个文件）。
网址加 `?fast=1` 可以跳过打字效果，方便测试。

## 每一间屋子的循环

1. **因为缺一样东西才进来。** 想听磁带 → 灯光间；想找维修记录 → 道具间；纽扣少了一件衣服 → 后台；联系不上人、手札里全是夜宵 → 后厨。
2. **调查。** 金色星标的是重要物品，小圆点是可看可不看的。也可以从「调查清单」进入。
3. **手札翻到一页空白，先写自己的。** 可以写，也可以留白，都能继续，不打分。
4. **找到他的。** 证物拼出他当年的答案，和自己那张并排放进手札。
5. **反推下一步缺什么。** 四种做法：圈线索（在一段话里点出关键词）、出示（从铁盒里选一样）、在画面里找、三选一推断（选错会说明为什么不对）。

顶栏的「声音 → 姓 → 名字 → 本人」是找人的进度。

## 文件

| 文件 | 内容 |
| --- | --- |
| `js/story.js` | 全部剧情文字与流程。改台词、加房间只动这里 |
| `js/art.js` | 全部画面（SVG）。重要物品是 `<symbol>`，只画一次，场景、铁盒栏、物品卡共用 |
| `js/game.js` | 引擎：对白、调查、特写、物品卡、手札、出示、圈线索、存档 |
| `css/game.css` | 界面样式 |
| `tools/build_single.py` | 打成单文件，用于发布预览 |

## 重要物品（全局统一）

| 物品 | 记号 | 出处 |
| --- | --- | --- |
| 手札 | 红色封皮，黑色束带，空白姓名贴 | 铁盒 |
| 磁带 R-17 | 米白壳，青色标签，手写 R-17 | 铁盒 |
| 裂掉的纽扣 | 黑底金色四角星，一道裂纹从线孔到边 | 铁盒 |
| 没用过的车票 | 粉色，海滨专线，检票处是空的 | 铁盒 |
| 铅笔 | 黄色 | 灯光间笔筒（用完即还） |
| 维修标签 | 米色，三行「修。」，署名只剩「林」 | 道具间收音机 |

后两间新增的关键物：主角服（红披风，左肩纽扣是后补的）、第七张合照（画面外伸进来一只手）、写了名字的碗、没拆封的碗、器材归还单（6.14，和车票同一天）。

四角星是话剧社《借星的人》那部戏的标记，只出现在纽扣、海报和那批戏服上。

负责人、室友（开场与灯光间）；狐狸学姐 胡黎（后台）；老周（后厨）；小林 林拾（结尾）。
